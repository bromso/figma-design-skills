# Listing: /design-brief

## Tagline

Ask before you build: interview, discover the file, and write a Spec.

## Description

Interviews you about a design task before anything gets built: what it's for, who uses it, what already exists in the file and any connected libraries, and a committed visual direction (never a generic default). Writes the answers into a Figma Spec (or a locked text frame, if Specs aren't available in your file), plays it back, and waits for your approval in chat before anything else runs.

Use it to start any new screen, flow, component, or design-system work — a settings area, a token set, a component library. Skip it for a quick, obvious edit like renaming a layer or changing one fill; the skill tells you so itself if you run it on something that small.

First command in the four-command workflow: `/design-brief` → `/design-plan` → `/design-build` → `/design-review`. For a small, well-scoped change it also writes the plan itself, so you go straight from `/design-brief` to `/design-build`.

Works in all three Budget modes — Lean, Standard, Generous — asking fewer or more questions per message depending on which one applies; it asks about your plan or credit budget in its first round of questions.

Typical cost: to be recorded after testing.
