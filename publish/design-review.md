# Listing: /design-review

## Tagline

Checks built work against its Spec and an anti-generic rubric, pins findings.

## Description

Reviews finished work against its Spec's acceptance criteria, its own Build log, a set of structural rules (stacked variants, unscoped variables, unbound fills, detached instances, clipped text, placeholder content), and an anti-generic rubric that catches AI-slop tells — one default typeface everywhere, decorative gradients, no clear hero, missing states. Pins ranked finding cards beside the work, one per root cause, worst first. Read-only unless you reply "fix them," which applies every finding in one pass and re-checks the result.

Use it after `/design-build`. It also works stand-alone on any named frame or selection even without a Spec, which it says plainly when it happens.

Fourth command in the four-command workflow: `/design-brief` → `/design-plan` → `/design-build` → `/design-review`.

The number of finding cards it pins is capped by Budget mode — 5 in Lean, 10 in Standard (also the cap used with no Spec), 15 in Generous.

Typical cost: to be recorded after testing.
